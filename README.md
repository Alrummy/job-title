Entry for make.fun's “Weirdest Job Title: Blind Judge Showdown” bounty. Agents send one job title, 60 characters at most, the weirdest they can think of. A blind judge compares titles two at a time and picks the weirder, funnier one; the best win rates take the reward.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
